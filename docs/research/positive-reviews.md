# 競合の習慣アプリで褒められている点（★4〜5 のレビュー）

調べた日：2026-10-19。コンセプトの「レビュー分析」（★1〜3、不満）と対にする調べ。

## 調べ方

- **対象**：App Store の日本と米国で、評価の数が多い習慣アプリ。米国20、日本14、合わせて34アプリ
  - 米国：Me+、Habit Tracker、Productive、Fabulous、Streaks、Days Since、Strides、Routine Planner、Do Habits、Grit、Life Reset、Atoms、Habit Rabbit、Habit-Bull、Habit Hub、Finch、Habitify、HabitKit、Habitica、Way of Life
  - 日本：継続する技術、みんチャレ、DotHabit、Habitify、リズムケア、マイルーティン、my nicca、Streaks、習慣化アプリ（ルーティンリマインダー）、習慣チェックカレンダー、習慣 Habit Tracker、HabitKit、Finch、Productive
- **レビュー**：各アプリの App Store の公開の Web ページに載っているレビュー（1つのアプリ・1つの国につき最大10件）。合わせて334件のうち、★4〜5 の **254件**（米国155、日本99）を分類した
- **分類**：1件ずつ読んで、褒めている点を14の項目に分けた（1件に複数あれば、それぞれ数える）。あわせて、褒めながら書かれている要望も拾った

### 気をつけること

- **件数が少ない**：不満の分析（約2,070件）の約8分の1。割合は大まかな傾向として見る
- **偏りがある**：Web のページに載るのは Apple が選んだレビューで、長くて役に立つものが多い。新しい順に全部を読んだわけではない
- **やらなかったこと**：App Store のレビューのフィード（RSS）は、いまはレビューが返ってこない。Web のページが内部で使う API は、公開されていないので使わなかった

## 結果：褒められている点

### 日本と米国の違い

- **米国**：「人生が変わった」という体験の話が多い（ADHD や心の不調の話も多い）。柔軟さ・続けたことが見える・やさしさを褒める割合が、日本より高い
- **日本**：シンプル・デザイン・広告がない・無料で使える・応援の言葉やスタンプの楽しさを褒める。褒めながら要望を書く人が多い（日本 73%、米国 55%）

## 褒めながら書かれている要望（多い順、おおよその件数）

1. **バグの修正・安定**（約34）：落ちる、記録が保存されない・消える、同期の不具合、通知の不具合
2. **値段**（約28）：サブスクではなく買い切り、無料で使える習慣の数を増やす、広告をなくす、日本向けの価格
3. **端末をまたぐ同期**（約22）：iPad・Mac・Web、iCloud の同期、Apple Watch
4. **繰り返しの柔軟さ**（約22）：月に何回、曜日を決めない週に何回、何日おき、「第2土曜」、曜日ごとの決まり
5. **予定の外の記録**（約12）：過去の日の記録、前もって記録、目標を超えた分の記録

ほかに、通知の細かい設定（約13）、色・アイコン・スタンプ・テーマを増やす（約11）、くわしい統計（約11）、ウィジェット（約8）、日本語に対応してほしい（5）。

## Ongo への示唆

| 調べで分かったこと | Ongo の今 | 次にすること |
|---|---|---|
| 「続けられた」が一番の褒め言葉（56%） | 節目のお祝い、連続、マス目 | ストアの説明とスクリーンショットで、機能より「続けられる」を前に出す |
| シンプル（39%） | 30秒で始められる、1タップで記録 | そのまま守る。機能を足すときは、はじめての画面を増やさない |
| 柔軟さ（34%）。日本の声「◯曜日にできなかったと落ち込まない」 | 週に何回、お休み、まとめてお休み、カスタム繰り返し | ストアで「休んでも途切れない」を一番の売りにする（声とそのまま重なる） |
| 値段（28%）。要望でも2番目 | 習慣は無制限で無料、広告なし、買い切り | ストアで「習慣はいくつでも無料・広告なし・買い切りあり」をはっきり書く |
| 続けたことが見える（26%、米国 32%） | 習慣の詳細のマス目、マス目のウィジェット | スクリーンショットにマス目のウィジェットを入れる |
| 楽しさ（24%）。日本は応援の言葉・スタンプ | イラスト（welcome・rest・milestone） | 「褒めすぎない」の範囲で、記録のあとのひとことや、イラストを少し増やすのを検討 |

| 要望3位は同期 | バックアップだけ（同期は将来） | 将来の同期を、早めに検討する材料になる |
