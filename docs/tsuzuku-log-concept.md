# つづくログ（Ongo）コンセプトと機能

最終更新：2026-10-19

---

## 1. コンセプト

### ひとことで
**習慣はいくつでも、ずっと無料。自分好みに整えれば、もっと使いやすく。**

休んでも途切れない、やさしくてわかりやすい習慣トラッカー。

### アプリ名
| 言語 | 名前 | ストア表記（案） |
|---|---|---|
| 日本語 | つづくログ | 習慣トラッカー - つづくログ |
| 英語 | Ongo | Ongo: Habit Tracker |

- 英語のサブタイトル案：Streaks that survive rest days
- 英語名の由来：「ongoing」（続いている）を短くした造語。on と go から「続いていく」と読める
- 英語名の決め方：既存の「Tsuzuku: Habit Streak Tracker」とまぎらわしく、英語圏で意味が伝わりにくいため「Tsuzuku Log」から変更。HabitKit や Finch のような、短くてどの言語でも読める名前にした
- アイコンの案：名前の2つの「o」を、記録の丸（できた日は塗りつぶし、お休みは中空）に見立てる

### 4つの約束
1. **習慣は無制限、記録はずっと無料**：習慣の数に上限はない。記録、取り消し、過去の日の修正、お休みは、ずっと無料。広告は出さない。
2. **休んでも途切れない**：週に何回でも連続記録がつながる。体調不良や旅行の日は「お休み」にできる。日付が変わる時刻を選べる。
3. **30秒で始められる**：アンケートもログインもいらない。候補をタップするだけで1つ目の習慣ができる。
4. **Proは「自分好みに整える」機能だけ**：見た目、通知、細かい繰り返し、分析など、使い込むほどほしくなる機能だけを有料にする。

### 対象
- 習慣アプリを使ったことがあり、課金・広告・データ消失・使いにくさに不満がある人
- 三日坊主になりがちで、完璧に毎日続けるのが苦しい人
- 夜勤や夜ふかしなど、生活のリズムが0時で区切れない人

## 2. 無料とProの線引き

| 機能 | 無料（ずっと） | Pro |
|---|---|---|
| 習慣の数 | **無制限** | 無制限 |
| 記録 | 記録、取り消し、過去の日の修正、お休み、数値の記録（水2L など）、上限型（週3杯まで など） | 同じ |
| 繰り返し | 毎日、曜日指定、週に何回 | **カスタム繰り返し**：何日おき、月に何回、第何曜日、やってからN日後、1日に何回、期間限定 |
| 通知 | 1つの習慣に1つ、1日のまとめ通知 | **複数の通知**：1つの習慣に何回でも、曜日ごとに違う時刻、まだやっていない習慣だけ再通知 |
| 並び | 手動で並べ替え（ウィジェットも同じ順） | 同じ |
| メモ | 文字のメモ、カレンダーの印、メモの一覧、書き出しに含める | **メモの検索** |
| 統計 | 連続日数、週と月の達成率 | **詳細統計**：1年の推移、曜日・時間帯ごとの得意と苦手、習慣どうしの比較、去年との比較 |
| 見た目 | 外観（システム／ライト／ダーク）、デフォルトのテーマ（アクセントはアイコンと同じ緑）、基本アイコン約30種。習慣の色はテーマの色 | **カラーテーマ**10色、**習慣の色**6色、**カスタムアイコン**（全アイコン、絵文字、自分の画像） |
| データ | iCloudバックアップ、書き出し（JSON・CSV）、他のアプリからの取り込み | 同じ |
| シェア | 連続記録のシェアカード（節目のお祝いと、習慣の詳細から） | **カードのデザイン追加**：カラーテーマの色、レイアウトの種類 |
| ウィジェット | 小・中（タップで記録）、記録のマス目（小・中） | 追加のデザイン、大きなウィジェット |
| 端末 | iPhone（Android） | Apple Watch・iPad・Macとの同期（候補） |

### 未定
- **写真つきのメモ**：実装するかどうか、無料かProかも未定
- **気分の記録**：実装するかどうか、無料かProかも未定
- **カラーテーマ10色**：`docs/design-sample/color-theme.png` の9色（Cocoa Dusk、Blue Horizon、Blush Harmony、Violet Dream、Cotton Bloom、Earthy Moss、Crystal Mist、Candy Pop、Midnight Linen）と Sunset Amber。10色目は仮

### 料金（案）
| | 日本 | 米国 |
|---|---|---|
| 月額 | 250円 | $1.49 |
| 年額 | 1,500円 | $9.99 |
| 買い切り | 3,600円 | $24.99 |

- 週ごとの課金はしない
- 月額は、まず1か月だけ試したい人の入口。年額は、月額で12か月払うより、日本で5割（3,000円→1,500円）、米国で4割強（$17.88→$9.99）安い。買い切りは年額の約2.5年分にし、まず年額で試して、気に入ったら買い切りに移れるようにする
- 日本と米国の価格は、1ドル150円前後でそろえる（$9.99 ≒ 1,500円、$24.99 ≒ 3,750円）
- 主な競合より安くする：HabitKit（年額 1,800円／$11.99、買い切り $29.99）、Habitify（年額 4,800〜7,800円／$39.99、買い切り $89.99）
- 値上げはレビューで強く嫌われる（不満の47%が課金）。あとから上げずにすむよう、この価格をずっと続ける前提で決める。値下げやセールはあとからでもできる
- 無料体験は付けない（無料版で十分に試せるため）
- 地域の物価に合わせて価格を変える（タイ、インドネシア、ブラジルなどは安く）
- 一度無料にした機能は、あとから有料にしない

## 3. 機能（MVP）

### はじめて使う
- 起動するとすぐ「きょう」の画面。アンケート、ログイン、課金画面は出さない
- よくある習慣の候補（水を飲む、読書、散歩、早寝、英語、お酒を控える）をタップで追加
- 「自分でつくる」から1画面で作成：名前、アイコン、色、頻度、通知

### 毎日の記録（きょう）
- 大きな丸をタップして記録
- 記録した直後に「取り消す」と「ひとこと」（メモ）の帯を表示
- 直近7日を点で表示。お休みは中空の丸で、連続は切れない
- 数値の記録（+250ml など）と、上限型（+1杯）
- きょうの達成数の表示

### 習慣の詳細
- いまの連続、最長の連続、達成率
- これまでの記録の一覧（ヒートマップ）
- 記録を直す：日ごとに「できた／お休み／記録する」を切り替え
- メモの表示と追加。メモがある日はカレンダーに印を付ける

### 振り返り
- 週と月の達成率、習慣ごとの達成率（無料）
- 1年の推移や曜日ごとの分析はPro。案内は画面の中で控えめに

### シェア
- **節目のお祝い**：連続が節目（7・30・100・365日など）に届いた記録の直後に、お祝いのカードを表示。「シェア」と「閉じる」だけを置き、閉じたら同じ節目では二度と出さない
- **いつでもシェア**：習慣の詳細の右上に共有ボタン。いまの連続でカードを作る
- カードに載せるもの：習慣の名前とアイコン、いまの連続日数、直近の点（お休みは中空の丸）、アプリ名
- カードに載せないもの：メモ、ほかの習慣、達成率（低い数字を人に見せない）
- 載せるかどうかを選べる：習慣の名前（「ひみつの習慣」に置き換えられる）
- 共有はOSの共有シートを使う（X、Instagram のストーリーズ、LINE、写真に保存など）。画像は縦長（9:16）と正方形（1:1）
- 設定で節目のお祝いを止められる

### マイページ
- 現在のプラン、Proでできること
- これまでの記録回数、続けた日数、最長の連続
- iCloudバックアップの状態

### 設定
- 1日の区切り（0時／2時／4時／6時）
- 週の始まり（日曜／月曜）
- 通知（許可のお願いは画面の中のカードで行う）、1日のまとめ通知
- 節目のお祝い（オン／オフ）
- 言語（11言語、端末の設定に合わせる）
- iCloud同期、書き出し（無料）、他のアプリからの取り込み（CSV）
- 外観（システム／ライト／ダーク、テーマ：無料はデフォルト、Proは10色）

### Pro
- 課金の案内はこの画面と、Pro機能を使おうとした瞬間の小さな説明だけ
- 年額、月額、買い切りを並べ（年額をおすすめとして表示）、価格、自動更新、解約方法、地域ごとの価格をはっきり書く
- 「無料のまま続ける」と「購入を復元」を必ず置く

### ウィジェットとアプリの外
- ホーム画面の小・中：タップで記録
- ロック画面：きょうの達成数、次の習慣
- コントロールセンター：ワンタップで記録

### 第2弾以降
- Apple Watch、iPad、Mac
- タイマー、ヘルスケアとの連携
- 写真つきのメモ、気分の記録（未定）

## 4. UI/UXの原則

代表の色：**落ち着いた緑**（ライト #4A7C59、ダーク #8DBF9C）。アイコン、起動画面、ストア、サイトに使い、無料のアプリのアクセントの色にする（背景や文字はモノクロ）。

参考にするデザイン：`docs/design-sample/` の画面（別のアプリの画面なので、見た目と部品の作りだけを参考にする）。大きな見出し、浮いたピル型のタブバー、角の丸いカード、Proバッジと鍵アイコン、曜日チップと頻度のプリセット、画面の中の許可カード、同期状態の表示。

1. **最初の習慣を30秒で作れる**
2. **1タップで記録、すぐ取り消せる**
3. **休んでも途切れない見せ方**：お休みは中空の丸
4. **Proの案内は、使おうとした瞬間だけ**：起動時のポップアップや、記録を止める表示は出さない
5. **課金画面は1つだけ**
6. **大事な状態が常に見える**：同期、最終バックアップ、日付の区切り
7. **アクセシビリティ**：文字サイズの変更、VoiceOver、色のコントラスト（どのテーマでも、ボタンの文字と背景は 4.5:1 以上）
8. **触ったときの気持ちよさ**：記録したときの振動と、さりげないアニメーション
9. **責めない言葉づかい**：「本当に？」と確認しない、褒めすぎない、失敗を強調しない
10. **アプリを開かずに記録できる**：ウィジェットとコントロールセンター
11. **レビュー依頼は1回だけ**：最初の習慣を完了した直後に出す
12. **シェアは押しつけない**：お祝いのカードは節目ごとに1回だけ。閉じても何も言わない。レビュー依頼と同じ日には重ねない

## 5. 多言語対応

対応言語：ja / en / zh-CN / zh-TW / ko / es / fr / de / pt / th / id

- 言語ごとにストアの名前・サブタイトル・キーワードを設定し、検索の入口を増やす
- AIで下訳し、主要6言語（ja/en/zh/ko/es/de）は母語話者が確認する
- 用語集を作る（例：連続記録 → 中国語「连续打卡」、スペイン語「racha」）
- 言語ごとに正しい字形のフォントを指定する（日本語に中国語の字形を混ぜない）
- ドイツ語とフランス語は約3割長いので、ボタンは文字に合わせて伸ばす
- タイ語は単語の間にスペースがないので、改行の処理に注意する
- 週の始まり、日付と時刻の書き方、小数点（2,5 L）は地域に合わせる
- ストアのスクリーンショットも言語ごとに作る
- サポートは日本語と英語の定型文から始める

## 6. 開発と公開

### 技術（案）
- Expo（Expo Router）で iOS と Android を同時に作る。pnpm を使う。進め方は [ios-app-playbook.md](./common/ios-app-playbook.md) と [app-common-features.md](./common/app-common-features.md)
- 多言語、課金、レビューのお願い、テーマは Yaylog からコピーする
- 電波がなくても動く設計。記録は端末に保存し（`expo-sqlite`）、iCloud にバックアップする。Android は自動バックアップ（Google ドライブはログインが要るので使わない）
- 課金は RevenueCat で管理
- ウィジェット、ロック画面、コントロールセンターは各OSの仕組み（iOS は SwiftUI と WidgetKit、App Intents）で作り、config plugin で組み込む
  - ウィジェットから記録できるよう、データは最初から App Group の共有の場所に置く
- iCloud バックアップは Expo の部品がないので、ライブラリか Expo Modules API で作る
- シェアカードは画面の部品を画像にして（`react-native-view-shot`）、OSの共有シートで渡す（`expo-sharing`）。画像は端末の中で作り、サーバーには送らない
- 通知は端末の中で予約する。iOS は予約が64件までなので、近い日の分だけ予約し、アプリを開くたびに予約し直す。記録したら（ウィジェットからでも）その日の通知を消す

### 公開の予定
- **2026年12月中旬**：11言語で一斉に公開（年末は審査が遅れるので、12月18日ごろまでに申請）
- **2027年1月**：新年の需要（習慣アプリの売上が最も大きい月）
- **2027年2月**：中国語・韓国語圏の旧正月にも需要の山がある可能性

### 集客
- ストアの名前に検索キーワードを入れる（「習慣トラッカー」「Habit Tracker」）
- 最初の習慣を完了した直後に、レビューを1回だけ頼む。レビューにはすべて返信する
- 他のアプリからの取り込みで、乗り換えの受け皿になる（DotHabit、Habitify など）
- X（Twitter）で開発の様子を公開する
- 節目のシェアカードを口コミの入口にする。カードの隅にアプリ名を入れる

## 7. 根拠（調査のまとめ）

### 市場
- 個人開発の HabitKit：公開から7か月後に検索上位に入って急成長。2026年1月は28日間で10万ドル超（本人公表）
- HabitKit の日本のストアでの評価は38件（米国は2,486件）。日本はまだ取られていない
- 日本の主要アプリがつまずいている：DotHabit（広告の導入、2026年8月の記録消失）、Habitify（日本価格の大幅値上げ）

### レビュー分析（日米23アプリ、★1〜3 約2,070件）
| 不満 | 割合 |
|---|---|
| 課金（無料が1〜3個、起動時の課金画面、自動課金、値上げ、買い切りがない） | 47% |

- メモの不満：文字数の上限が短い（DotHabit）、書き出しに含まれない（Grit）

## 8. リスク

- 習慣アプリの競合はとても多く、機能はまねされやすい。勝負は品質（バグがない、言語が自然）と速さ
- 習慣を無制限に無料にするため、有料に移る人の割合は下がる可能性が高い。ダウンロード数（11言語、高い評価、口コミ）で補う
- 健康・習慣カテゴリでは、上位10%のアプリが売上の約9割を取る
- 英語名「Ongo」は、別のジャンルに同じ名前がある（カメルーンの配車アプリ、SaaS企業、暗号資産）。習慣アプリでは見つからなかった（2026-10-19のWeb検索）。ongo.com は取れない可能性が高い
